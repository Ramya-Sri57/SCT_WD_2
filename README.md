# Stopwatch Web Application

An interactive and user-friendly Stopwatch Web Application developed using HTML, CSS, and JavaScript.

This project was completed as **Task 02** during my Web Development Internship at SkillCraft Technology.

---

##  Features
- Start Stopwatch
- Pause Stopwatch
- Reset Stopwatch
- Lap Time Tracking
- Accurate Time Measurement
- Responsive User Interface
- Simple and Interactive Design
